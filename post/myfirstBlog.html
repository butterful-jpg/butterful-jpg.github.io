我的第一篇博客

Created2026-11-28|Updated2026-11-28|技术
|Post Views:

今天终于搭好了自己的第一个博客，记录一下搭建过程和踩到的坑，方便以后回看。

用了什么

  • 框架: Hexo
  • 主题: NexT
  • 托管: GitHub Pages
  • 编辑器: VS Code

搭建步骤

  1. 安装 Node.js，自带 npm
  2. 全局安装 Hexo: npm install -g hexo-cli
  3. 初始化博客目录: hexo init
  4. 安装依赖: npm install
  5. 本地预览: hexo server
  6. 部署到 GitHub Pages: hexo deploy

踩过的坑

在配置 front-matter 的时候，YAML 语法的格式要求非常严格。特别是列表项 - 后面必须加一个空格，否则会导致整个文件解析失败，文章莫名其妙地消失。
